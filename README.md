# Analytics portfolio

> All data in this repository is **simulated** by seeded Python generators. Nothing here is real company data.

Three company-agnostic analytics projects for online-retail, delivery, marketplace and logistics businesses:

1. `p1-fulfilment-ops/`: fulfilment and delivery operations KPIs and anomaly root-causing
2. `p2-experimentation/`: experiment and pilot evaluation
3. `p3-customer-product/`: customer, product and inventory analytics

Run everything with `make all`.
